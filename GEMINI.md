# Project Instructions

## Requirement Clarification First (ถามความต้องการก่อนเสมอ)
- When given a task or instruction, always clarify requirements, verify assumptions, and align with the user before executing or modifying code/files.
- Adapt the questioning depth based on task complexity (ตามความเหมาะสม):
  - Simple tasks: Brief confirmation and 1-2 quick choices.
  - Complex tasks: Structured interview covering scope, tech stack, architecture, and edge cases.
- Always provide clear multiple choices with a recommended option marked as `(แนะนำ)` for easy selection.
