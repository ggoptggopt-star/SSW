# Student Submission Portal (ระบบส่งงานและตรวจงานนักศึกษา)

เว็บแอปพลิเคชันระบบจัดการและส่งงานสำหรับนักศึกษาและอาจารย์ ออกแบบด้วยธีม **Minimal & Elevated** สวยงาม เรียบหรู ใช้งานง่าย พร้อมเชื่อมต่อฐานข้อมูล **Supabase** แบบเรียลไทม์

---

## ✨ ฟีเจอร์หลัก (Key Features)

### 👨‍🎓 มุมมองนักศึกษา (Student Portal)
- **Dashboard & Assignments**: ดูรายการใบงาน กำหนดส่ง (Deadline) และสถานะการส่งงาน
- **ส่งงานรายบุคคล / กลุ่ม**: แนบไฟล์ PDF, รูปภาพ หรือลิงก์ภายนอก (Figma, Canva, Google Drive) พร้อมระบุรายชื่อสมาชิกกลุ่ม
- **Grades & Feedback**: ตรวจสอบคะแนนที่ได้รับและข้อเสนอแนะ (Feedback) จากอาจารย์ผู้สอน
- **ระบบสมาชิก**: เข้าสู่ระบบ / สลับบัญชีนักศึกษา

### 👨‍🏫 มุมมองอาจารย์ (Instructor Portal)
- **ภาพรวมวิชา**: ดูสถิติใบงานทั้งหมด งานที่ส่งเข้ามา และจำนวนนักศึกษาในระบบ
- **จัดการใบงาน (Assignment Management)**: สร้าง แก้ไข หรือลบใบงาน กำหนดคะแนนเต็ม รูปแบบเดี่ยว/กลุ่ม และกำหนดเวลาส่ง
- **ตรวจงาน & ให้คะแนน (Grading & Feedback)**: ตรวจสอบไฟล์งาน ลิงก์งาน และบันทึกคะแนนพร้อมคอมเมนต์ให้นักศึกษา
- **ภาพรวมคะแนนนักศึกษาทั้งหมด**: ดูตารางคะแนนรวมและสถานะการส่งงานของนักศึกษาทุกคน
- **Export Data**: ส่งออกคะแนนเป็นไฟล์ Excel/CSV และดาวน์โหลดงานที่ส่งทั้งหมด

## 🎨 Design System
- **โทนสีหลัก (Color Palette)**: Deep Navy (`#0F2942`), Olive Moss (`#4A5638`), Warm Cream (`#EFECE3`), Sand Beige (`#D5C7B2`)
- **Typography**: Playfair Display (หัวข้อเน้นความภูมิฐาน) + Plus Jakarta Sans / Noto Sans Thai (เนื้อหาอ่านง่าย)
- รายละเอียดเพิ่มเติมดูได้ที่ [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)

---

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)
ระบบรองรับการเชื่อมต่อกับ **Supabase** ผ่าน Client API โดยมีตารางหลัก:
- `students`: ข้อมูลนักศึกษา
- `assignments`: ข้อมูลใบงาน
- `submissions`: ข้อมูลการส่งงานของนักศึกษา
- `teachers`: ข้อมูลอาจารย์ผู้สอน

> ดู SQL Script สำหรับสร้างตารางและ RLS Policies ได้ที่ [supabase_schema.sql](supabase_schema.sql)

## 🚀 วิธีเปิดใช้งาน (Getting Started)
1. Clone หรือดาวน์โหลดโปรเจกต์นี้
2. เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (หรือใช้ Live Server บน VS Code)
3. ระบบจะเชื่อมต่อกับ Supabase และพร้อมใช้งานได้ทันที
